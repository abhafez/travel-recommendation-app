# Travel Recommendation Web App

Final project for the Coursera "HTML, CSS, and JavaScript for Web Developers" course.

A travel recommendation website with:
- Home page with intro and search
- About Us page
- Contact Us page with a working email form
- Navigation bar across all pages
- Search feature returning beach, temple, and country recommendations (each with two images)

## Live site

Deployed via GitHub Pages: see repository "About" section / Pages settings for the link.

## Tech

Plain HTML, CSS, and vanilla JavaScript (`fetch` + JSON data file, no frameworks).
